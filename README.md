# আর-রিহলা (Ar-Rihla) Android App — v3.0

## GitHub থেকে APK তৈরির নিয়ম:
1. ZIP ফাইলটি এক্সট্র্যাক্ট করুন।
2. এক্সট্র্যাক্ট করা সব ফাইল ও ফোল্ডার (`.github` ফোল্ডারসহ) আপনার GitHub রিপোজিটরির রুটে আপলোড করুন।
3. GitHub-এর **Actions** ট্যাবে গিয়ে **Build Android APK** রান সম্পন্ন হলে **Artifacts** থেকে `Ar-Rihla-debug-apk` ডাউনলোড করুন।
